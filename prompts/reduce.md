## 骨架怎么用

1. **把 model 放进草稿头部**：`## 这一章真正在解决什么`，把这个 model 写进去（可以润色措辞，不许换掉它的判断）。
2. **把 `teachingOrder` 放进 `### 讲解顺序`**：写出你选定的顺序与理由。
   - `shape: source` → 写原序，并说明**为什么原序本身就在一步步搭出这个模型**。
   - `shape: reordered` → 写重排后的顺序，并说明**原序哪里挡路**。
   两种都要写理由。理由必须能让读者看懂（这不是原书的顺序，以及为什么不是）。
3. **按 `teachingOrder.steps` 排第一节的小标题顺序**。原书顺序在这里可以被打破——这是 model-shaped 与 source-shaped 的分界点。
   - 档案的**大节**顺序（一 → 二 → 三 → 四）是四类声音的隔离，不许动。
   - **小标题的顺序**才是讲解顺序，按 model 排。
4. **每个 point 挂到它对骨架最有用的那个位置**，而不是它原来在原文里的位置。
5. **骨架覆盖不到的材料不要硬塞**。塞不进去的，要么放进（本节留下的口子），要么就是这一步该跳过的细节。

## 上游块的精读结果

上游是**按 point 交付的**，每个 point 有四个槽位：`claim`（主张）/ `evidence`（证据）/ `mechanism`（机制）/ `boundary`（边界），以及一个 `missing` 数组，标明它哪个槽位没填出来（只能取 `mechanism` / `boundary` / `evidence`）。

**这些 point 是按原文顺序、按分块边界给你的。别把这个顺序当成讲解顺序**——它是原材料，不是结构。

## 四个槽位落到哪里（别放错地方）

| 上游的槽位 | 写进档案的哪里 |
|---|---|
| `claim` 主张 + `quote` 逐字引文 | **第一节**的（作者主张），引文原样带过去 |
| `evidence` 证据 + `quote` | **第一节**的（关键证据／例子） |
| `mechanism` 机制 | **第二节**某条推演的（理由） |
| `boundary` 边界 | **第二节**同一条推演的（限制） |
| `missing` 里标了 `boundary` | （限制）写（原文未给边界），不要自己编一条 |
| `missing` 里标了 `mechanism` | 不写这一条推演的（理由），或写明（机制未推出） |

**机制和边界绝不进第一节。** 第一节只放作者明说的东西和逐字引文。把推出来的机制写进第一节，就是替作者说话——这是这个插件最不能接受的一种失真，插件和你的自检都会拦它。

## 写完之后必须自检（五条，不合规就重写）

写完不要直接落盘。逐条核对，**不合规就重写到合规为止，写入草稿的必须是修正后的版本**：

1. **骨架是不是 model 的形状**（这一条比其他四条都重要）：把草稿头部遮住，只看第一节的小标题顺序——它读起来像（这一章在解决 X 的几个环节），还是像（原文第一节、原文第二节、原文第三节）？
   如果是后者，你只是把 point 按原序抄了一遍，等于没有用骨架。**重排**。
2. **短句**：有没有段落超过 4 句？有就拆开。宁可多分段，不要写长段。
3. **四步齐全**：每个 point 是否都讲全了（主张 → 证据 → 机制 → 边界）？
   缺证据的（上游标了 `missing: ["evidence"]`）要在（本节留下的口子）里点明；缺机制或缺边界的按上面的表处理，**不要硬编**。
4. **AI 视角是增量还是替代**：每个小标题后面那段（AI 视角），写的是作者没明说但推得出来的东西，还是把作者的话换了个说法重讲一遍？后者等于冒充作者又冒充自己，重写。
   推不出新东西时，就写（这一节我没有额外的补充）。
5. **有没有残留提问句式**：正文里出现（你怎么看）（你觉得）（你能……吗）（你想不想）这类把球踢回给读者的写法，一律删掉。这个插件的定位是深度讲解，不是共读提问。**引文里的问句保留**——那是作者在问。

## 其他纪律

1. **引文只从上游给你的 `quote` 字段里取，原样复制**。不要自己新写引文、不要凭印象补引文、不要改写标点。
   需要一条上游没给的引文时，说明证据不足——那就把它写进（本节留下的口子），而不是自己造一条。
2. **合并同类，保留分歧**。多个块说同一件事就并成一条；两个块互相矛盾时，两条都留下，并在（本节留下的口子）里点明这处矛盾。矛盾是最有价值的信息，不要抹平。
3. **第三节原样保留 `（待读者填写）`**。那是读者的位置，你不知道读者怎么想。写了内容会被插件判为（替读者说话）而拒收。
4. **作者的限定词要保住**。原文说（在多数情况下）（至少在这两个县），就不要在档案里升格成普适结论——丢掉限定词是最常见、也最难被发现的一种失真。限定词通常正是上游 `boundary` 槽位里的东西。
5. **章末必须有（在全书中的位置）**。讲功能，不讲内容摘要：这一章在论证链里解决掉什么、打开什么、为哪一章铺路。
6. （本节留下的口子）不要写套话。作者回避了什么、哪个断言没有证据、哪个概念没有定义，具体写出来。
